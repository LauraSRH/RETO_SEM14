# RETO_SEM14
Programa que permite el ingreso de datos, como nombre, teléfono y correo electrónico en una agenda, generando un documento
cvs.
Apoyada por la IA, se realiza el import os. Cumpliendo con los requisitos establecidos para el reto, se usaron las funciones de if, 
with .. as, for para llamar al archivo. Para el ingreso de los nuevos contactos while, elif, excpetion y brake. 
Se inicia con la lista de personas, llamar a través de la ruta el archivo en caso de que ya exista. 
Con input se ingresan los datos y da 4 opciones donde 1 es agregar contacto, 2 modificar contacto, 3 mostrar contactos y 4 salir.
